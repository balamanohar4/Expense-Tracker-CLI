# Expense Tracker CLI

A Java command-line expense tracker for recording, managing, analyzing, and reporting personal expenses.

## Features

- Add expenses with amount, category, description, and date
- View all recorded expenses
- Delete expenses
- Search expenses by category or description
- Generate monthly expense reports
- View expense statistics
- Export expenses to CSV
- Sort expenses by date
- Sort expenses by amount (low to high / high to low)
- Set and track a monthly budget
- View category-wise spending
- Generate date-range expense reports
- Check current monthly budget status
- View an expense dashboard
- Automatically save and load expense data

## Technologies Used

- Java
- ArrayList
- HashMap

- Comparator

## Data Storage

The application automatically saves expense data using Java object serialization.

Generated data files:

- `expenses.dat` - Stores the application's expense data
- `expenses.csv` - CSV export generated by the application

These generated files are excluded from Git tracking through `.gitignore`.

## How to Run

### 1. Clone the repository

`git clone https://github.com/balamanohar4/Expense-Tracker-CLI.git`

`cd Expense-Tracker-CLI`

### 2. Compile the Java files

`javac Expense.java Main.java`

### 3. Run the application

`java Main`

## Example Workflow

The application provides a command-line menu for managing expenses.

Typical workflow:

1. Add an expense
2. View expenses
3. Search or sort expenses
4. Generate reports
5. Review statistics and category-wise spending
6. Check monthly budget status
7. Export expenses to CSV
